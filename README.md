Sistema de Cadastro de Alunos

Um sistema simples de console em C# para gerenciar o cadastro de alunos. Permite adicionar, listar, remover e atualizar alunos, guardando nome, idade e nota de cada um.

Estrutura
Aluno.cs — classe que representa o aluno (nome, idade, nota).
CadastroAlunos.cs — lógica de cadastro (adicionar, listar, remover, atualizar).
Program.cs — menu interativo no console.
